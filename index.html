Scan to G‑code, in one click

Irontronics · Summer Intern · May 2026 – Present

At Irontronics I own the full image-processing pipeline that reads metal part outlines and bolt-hole positions from camera frames and writes G‑code: camera capture, Otsu thresholding, boundary tracing, hole detection, and the G‑code engine. It runs as a zero-dependency browser application.

Press run to scan the part.

This bench re-creates the pipeline in your browser on a synthetic part, with a demo scale of 0.5 mm per pixel. The real tool runs on live camera frames with manual pixel-to-mm calibration.

; G-code appears here after the scan.
  • AccuracyMillimetre-level dimensional accuracy through manual pixel-to-mm calibration, using contour tracing and binary segmentation.
  • ImpactReplaces physical calliper workflows with a single-click scan-to-G-code pipeline, cutting manual measurement and CAM setup time on custom metal parts.
  • NextEditing the generated G-code file to make design improvements.
  • StackHTML · CSS3 · Canvas API · WebRTC · Blob API · Python · JavaScript · React · TypeScript

Debug Odyssey

Story-driven EdTech game · September 2026 · Finalist, Celestia 2.0

A web game that teaches beginner programmers to read, decode, and fix compiler errors across five major languages. An immersive 50-level campaign replaces panic with structured problem-solving, building real debugging confidence.

Under the hood: a Monaco editor workspace on the front end, and a secure, sandboxed FastAPI execution backend running multi-language compilers, containerised with Docker and deployed across Vercel and Google Cloud Run. Next up: a 2D world with visual task completion in Phaser.js.
